# Lisensi musik

Kedua bed musik di folder ini DISINTESIS secara deterministik oleh proyek
Dalang sendiri (pad sinus berlapis + noise ter-filter; sumber pembangkitnya
di-commit di riwayat repo) dan dirilis sebagai **CC0 1.0 / public domain** —
bebas dipakai, diubah, dan didistribusikan, termasuk komersial, tanpa
atribusi.

- `tenang.wav` — pad hangat, progresi minor lembut, 48 dtk loop mulus.
- `cerah.wav` — pad mayor lebih terang, 48 dtk loop mulus.

Format: WAV PCM 16-bit mono 22.05 kHz (konten spektrum rendah; ukuran repo
dijaga kecil). Direferensikan dari scene-plan sebagai `pustaka:<nama>`.
